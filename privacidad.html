🔒 Política de privacidad

1. Responsable del tratamiento

RemaCards gestiona esta página web dedicada a la venta y coleccionismo de cartas de fútbol.

2. Información recopilada

Los datos que el usuario pueda proporcionar mediante contacto directo serán utilizados únicamente para responder consultas, gestionar compras o resolver incidencias.

3. Uso de los datos

Los datos personales no serán utilizados para fines distintos a los necesarios para la comunicación con el cliente.

4. Protección de datos

RemaCards aplica medidas razonables para proteger la información proporcionada por los usuarios.

5. Comunicación con clientes

La comunicación puede realizarse mediante WhatsApp, correo electrónico u otros canales indicados por RemaCards.

6. Derechos del usuario

El usuario puede solicitar información, modificación o eliminación de sus datos cuando corresponda.

7. Contacto

Para cualquier consulta relacionada con privacidad puedes contactar con RemaCards desde la página de contacto.
